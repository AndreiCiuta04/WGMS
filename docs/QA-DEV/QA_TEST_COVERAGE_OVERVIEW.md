## Commands

| Test layer | Command | What it runs | Notes |
|---|---|---|---|
| Backend full tests | `cd backend && mvn test` | All backend unit and integration tests. | Requires local Java/Maven environment and test database setup used by the project. |
| Frontend unit tests | `cd frontend && npm test -- --watch=false` | Angular/Karma frontend unit tests. | Headless single run. |
| Frontend build | `cd frontend && npm run build` | Angular production build. | Verifies TypeScript/template compilation. |
| Full Cypress E2E | `cd e2e && npx cypress run` | All feature and use-case Cypress specs. | Requires backend at `http://localhost:8080/api/v1` and frontend on Cypress base URL. |
| FR feature Cypress examples | `cd e2e && npx cypress run --spec cypress/e2e/fr12-dashboard.cy.js` | A single feature spec. | Replace the spec path with another `cypress/e2e/fr*.cy.js` file as needed. |
| Use-case Cypress examples | `cd e2e && npx cypress run --spec cypress/e2e/usecases/uc01-onboarding-household.cy.js` | A single use-case journey spec. | Replace the spec path with another `cypress/e2e/usecases/*.cy.js` file as needed. |
| Interactive Cypress | `cd e2e && npx cypress open` | Cypress UI mode. | Useful for debugging and demos. |
| Project E2E runner | `./run-e2e.sh` | Menu for all E2E tests, all FR specs, all use-case specs, individual specs, headless, and interactive modes. | Run from repository root. |
